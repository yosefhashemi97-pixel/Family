# Family — وب‌سایت عضویت

این پروژه یک شروع قابل اجرا برای سایت Family است: ثبت‌نام بدون شماره تلفن، ورود، فهرست عمومی نام کاربری اعضا و مسیر محدودشده مدیر.

## اجرای محلی

1. Node.js نسخه 18 یا جدیدتر نصب کنید.
2. در پوشه پروژه دستور `npm install` را اجرا کنید.
3. یک مقدار تصادفی و طولانی برای `SESSION_SECRET` تنظیم کنید.
4. سپس `npm start` را اجرا کنید.
5. در مرورگر `http://localhost:3000` را باز کنید.

نمونه تنظیم متغیرها در Linux/macOS:

```bash
export SESSION_SECRET="یک-عبارت-تصادفی-طولانی-و-منحصر-به-فرد"
export ADMIN_USERNAME="نام_کاربری_مدیر"
npm start
```

در Windows PowerShell:

```powershell
$env:SESSION_SECRET="یک-عبارت-تصادفی-طولانی-و-منحصر-به-فرد"
$env:ADMIN_USERNAME="نام_کاربری_مدیر"
npm start
```

ابتدا با همان نام کاربری که در `ADMIN_USERNAME` تعیین کرده‌اید ثبت‌نام کنید. مسیر `/api/admin/members` فقط برای آن حساب، ایمیل اعضا را برمی‌گرداند. رمزهای عبور هش می‌شوند و هیچ‌وقت در فهرست اعضا برگردانده نمی‌شوند.

## قبل از انتشار عمومی

- `SESSION_SECRET` را حتماً با مقدار تصادفی قوی تنظیم کنید.
- فقط روی میزبانی دارای HTTPS و با `NODE_ENV=production` اجرا کنید.
- برای انتشار واقعی، از session store پایدار (نه حافظه پیش‌فرض Express)، پشتیبان‌گیری امن از SQLite و سیاست حریم خصوصی استفاده کنید.
- فهرست عمومی فقط نام کاربری را نشان می‌دهد؛ ایمیل و رمز عبور عمومی نیستند.
- در این نسخه ثبت‌نام با ایمیل و رمز عبور است و تأیید ایمیل پیاده‌سازی نشده؛ برای انتشار عمومی بهتر است تأیید ایمیل و بازیابی امن رمز اضافه شود.
- اطلاعات مدیر فقط از طریق تنظیمات محیطی سرور تعیین می‌شود؛ آن را داخل کد یا در مرورگر قرار ندهید.

این بسته سورس پروژه است و خودش به‌تنهایی روی اینترنت منتشر نمی‌شود؛ برای آنلاین شدن باید روی یک سرویس میزبانی Node.js مستقر شود.
